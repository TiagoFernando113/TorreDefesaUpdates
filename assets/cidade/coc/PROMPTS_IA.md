# Prompts para gerar sprites dos prédios (IA)

Use em qualquer gerador de imagem (Bing/DALL·E, Leonardo, Midjourney, etc).
**Salve cada PNG com o nome exato indicado** em `assets/cidade/coc/` (sobrescreve o SVG).
O código carrega automático — não precisa mexer em nada.

## Especificação comum (cole junto de cada prompt)
> isometric game building sprite, Clash of Clans style, 3/4 top-down view,
> centered, **transparent background**, no text, no shadow on ground edges,
> clean cartoon shading, vibrant colors, single building, 512x512, PNG
