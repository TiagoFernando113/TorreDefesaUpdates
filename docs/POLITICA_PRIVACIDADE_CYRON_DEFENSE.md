# Politica de Privacidade - Cyron Defense

Ultima atualizacao: 16/05/2026

Esta politica explica como Cyron Defense coleta, usa e protege informacoes dos jogadores.

## 1. Dados que o jogo pode coletar

Cyron Defense pode coletar ou armazenar os seguintes dados, dependendo dos recursos usados pelo jogador:

- Apelido/nome de jogador usado no perfil e no ranking.
- Email informado para criar ou recuperar conta.
- Senha em formato protegido por hash para autenticacao.
- Identificador interno de jogador, como player_id.
- Progresso do jogo, save, inventario, comandantes, skins, talentos, mapas, estatisticas, pontuacao e historico de partidas.
- Dados de ranking, como score, melhor wave, temporada e posicao.
- Avaliacoes, feedbacks e mensagens enviadas pelo proprio jogador dentro do jogo.
- Codigo ou identificador de vinculacao com Discord, quando o jogador escolher usar esse recurso.
- Configuracoes locais do jogo, como volume, acessibilidade e preferencias.
- Chave de API de TTS informada pelo proprio jogador, caso ele use recurso avancado de acessibilidade por voz.

O jogo nao pretende coletar contatos, localizacao, fotos, videos, microfone, camera, SMS ou dados bancarios diretamente.

## 2. Como usamos os dados

Usamos os dados para:

- Criar e acessar a conta do jogador.
- Salvar e recuperar progresso local ou online.
- Exibir ranking e recompensas de temporada.
- Sincronizar progresso entre dispositivos.
- Melhorar a experiencia do jogo e corrigir problemas.
- Processar avaliacoes e feedbacks enviados pelo jogador.
- Ativar recursos de acessibilidade, quando escolhidos pelo jogador.
- Vincular conta ao Discord, quando o jogador solicitar.

## 3. Servicos de terceiros

Cyron Defense pode usar servicos de terceiros para operar recursos online:

- Supabase: usado para conta, ranking, save online, avaliacoes, recompensas e vinculacao com Discord.
- Google Text-to-Speech ou servicos de voz: usados apenas quando recursos de acessibilidade por voz forem ativados/configurados.
- Google Play: podera ser usado no futuro para distribuicao do jogo e compras dentro do app, se esse recurso for ativado.
- Discord: usado apenas quando o jogador escolher abrir ou vincular recursos relacionados a comunidade.

Esses servicos podem processar dados conforme suas proprias politicas de privacidade.

## 4. Compras e anuncios

No estado atual, Cyron Defense nao possui anuncios ativos.

O jogo possui itens premium planejados. Quando compras pela Google Play forem conectadas, o pagamento sera processado pela Google Play. Cyron Defense nao armazenara dados completos de cartao ou informacoes bancarias.

## 5. Compartilhamento de dados

Nao vendemos dados pessoais dos jogadores.

Dados podem ser compartilhados apenas quando necessario para:

- Operar ranking, conta e save online.
- Processar recursos escolhidos pelo jogador, como Discord ou TTS.
- Cumprir obrigacoes legais.
- Proteger o jogo contra abuso, fraude ou uso indevido.

## 6. Armazenamento e seguranca

Parte dos dados fica salva no dispositivo do jogador. Quando o jogador usa conta online, parte dos dados tambem pode ser enviada para servidores usados pelo jogo.

Senhas nao devem ser armazenadas em texto puro pelo jogo; o jogo usa hash para autenticacao. Mesmo assim, nenhum sistema e totalmente imune a riscos. Por isso, o jogador deve usar uma senha diferente de senhas importantes de outros servicos.

Mantemos os dados enquanto forem necessarios para operar a conta, o ranking, o save online e os recursos do jogo.

## 8. Criancas e publico-alvo

Cyron Defense tem classificacao pretendida Livre, sujeita a confirmacao pelo questionario oficial de classificacao indicativa da Google Play.

O jogo nao e direcionado especificamente a criancas pequenas.

Se o jogo for publicado com publico infantil ou familia na Google Play, esta politica devera ser revisada para cumprir todas as regras aplicaveis a criancas e familias.

Esta politica pode ser atualizada quando novos recursos forem adicionados, como compras, anuncios, novos recursos online ou mudancas na forma de armazenamento.
