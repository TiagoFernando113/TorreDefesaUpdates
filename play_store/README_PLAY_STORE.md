# Pasta Play Store - Cyron Defense

Esta pasta separa os arquivos iniciais para preparar a pagina do jogo na Google Play.

## Graphic assets

- `graphic_assets/icone_512x512.png` - icone principal para cadastro da loja.
- `graphic_assets/feature_graphic_1024x500.png` - banner/feature graphic.
- `graphic_assets/icone_adaptativo_foreground_432x432.png` - apoio para icone adaptativo Android.
- `graphic_assets/icone_adaptativo_background_432x432.png` - apoio para icone adaptativo Android.
